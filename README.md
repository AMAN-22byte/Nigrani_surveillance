**Nigrani Surveillance**
Nigrani Surveillance is an AI-powered surveillance system designed to enhance security through intelligent monitoring. This project leverages modern web technologies to provide real-time surveillance capabilities.

🚀 Features
Real-Time Monitoring: Stream live video feeds for immediate surveillance.

Intelligent Detection: Incorporate AI models to detect unusual activities or objects.

User-Friendly Interface: Interactive dashboard built with Next.js and Tailwind CSS.

Scalable Architecture: Modular design to support camera feeds from any device and locations.
